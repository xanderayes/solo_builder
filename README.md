# Piano Tiles

A rhythm/reflex game built with Godot 4.2.

## How to Play

- Click to start the game
- Black tiles will fall from the top in 4 columns
- Click on the black tiles before they reach the bottom
- Don't click on white space
- Score increases with each tile clicked
- Speed increases every 10 points
- Game ends if you miss a tile or click white space

## Controls

- Left mouse click to tap tiles

## Project Structure

- `scenes/main.tscn` - Main game scene
- `scenes/tile.tscn` - Tile scene
- `scripts/main.gd` - Main game logic
- `scripts/tile.gd` - Tile logic

## Running

Open the project in Godot 4.2 and press F5 to run.
